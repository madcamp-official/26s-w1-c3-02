# Project Structure

## 현재 상태

프로젝트가 기획 단계이며, 저장소에는 `README.md`와 이 `.kiro/` 문서 외 실제 소스 코드가 없다.

```
26s-w1-c3-02/
├── README.md          # 기획안, 기능 명세서, IA/DB/API 문서 틀
└── .kiro/
    └── steering/       # 이 디렉토리 (product.md, tech.md, structure.md)
```

## README.md 문서 구성

`README.md`는 프로젝트 진행 단계에 맞춰 아래 섹션을 순서대로 채워나가는 구조로 되어 있다:

1. 팀원
2. 기획안 (주제/목적/핵심 기능/예상 사용자/역할)
3. 기능 명세서 (필수/선택 기능)
4. IA 및 화면 설계서 (와이어프레임)
5. DB 스키마 (ERD)
6. API 문서
7. 배포 결과물
8. 회고 문서 (KPT)

기능이나 설계가 바뀌면 코드보다 먼저 이 섹션들을 갱신하는 것을 원칙으로 한다.

## 향후 구조 (예정)

기술 스택이 정해지면 (`tech.md` 참고), 프론트엔드/백엔드 디렉토리 분리 여부와 모노레포 구성을 이 문서에 반영할 예정. 소스 코드가 추가되는 시점에 실제 폴더 구조와 네이밍 컨벤션으로 이 섹션을 대체할 것.
