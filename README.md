## 기획안

> 프로젝트 주제, 목적, 핵심 기능, 예상 사용자, 팀원별 역할 등 정리

- **주제:** 책에 주석을 달 수 있는 웹 서비스 (가제: *주석노트*)

- **목적:**
  - 혼자 읽고 끝나던 독서 경험을, 책의 특정 구절에 **주석·질문·토론**을 남기며 생각을 기록하고 나눌 수 있는 경험으로 확장한다.
  - 저작권 문제를 피하면서도 "책 속 특정 위치"에 메모를 고정할 수 있도록, 사용자가 직접 입력한 페이지·구절을 기준으로 주석을 관리한다.
  - 공개/비공개 설정을 통해 개인 독서 노트와 공유형 독서 토론을 하나의 서비스에서 모두 지원한다.
  - 주석을 **남기는 사용자**와 특정 구절의 해설·해석을 **찾아보는 사용자**를 연결하여, 한 권의 책을 매개로 한 집단 지성 독서를 지원한다.

- **핵심 기능:**
  - **책 선정:** 홈 화면에서 주석을 달 책을 선택하거나 새로 등록 (제목·저자 등 기본 정보 입력)
  - **주석 카드 작성:** 선택한 책에 대해 **주석 / 질문 / 토론** 유형의 카드를 생성
    - 저작권 보호를 위해 책 본문은 제공하지 않으며, 사용자가 **페이지 번호와 인용 구절을 직접 입력**해 카드에 연결
    - 카테고리별 댓글 타입 구분
  - **공개/비공개 설정:** 카드별로 공개 여부를 지정 — 비공개는 본인만, 공개는 다른 사용자도 열람 가능
  - **카드 열람·관리:** 책 단위로 주석 카드를 모아 보고, 유형별로 확인·수정·삭제
  - **주석 검색:** 책의 **페이지 번호 또는 구절(키워드)로 공개 주석 카드를 검색** — 이해가 안 되는 부분에 대해 다른 사용자가 남긴 주석·질문·토론을 바로 찾아볼 수 있음 (검색 범위: 우선 선택한 책 내부, 페이지 번호 + 인용 구절·주석 본문 키워드 대상)
  - 책 하나를 선택해서 독서방 생성/ 멤버 초대/ 각자 구절 카드 올리기/ 서로 주석 달기

- **예상 사용자:**
  - 읽은 책의 인상 깊은 구절과 생각을 구조적으로 기록하고 싶은 개인 독자
  - 같은 책을 읽으며 질문과 해석을 나누고 싶은 독서 모임·스터디 참여자
  - 특정 구절에 대한 토론을 남기고 공유하고 싶은 학생·연구자
  - 책을 읽다가 이해가 안 되는 부분이 있을 때, 해당 페이지·구절의 공개 주석을 검색해 도움을 얻으려는 독자 (주석을 소비하는 사용자)

## 기능 명세서

> 구현할 기능을 사용자 관점에서 정리하고, 필수 기능과 선택 기능을 구분

### 필수 기능

회원 관리 기능
  사용자는 회원가입 및 로그인을 통해 개인 계정을 생성하고 사용할 수 있다.  
  로그인한 사용자는 자신의 즐겨찾기 목록, 작성한 구절 노트, 주석 기록 등을 개인 계정에 저장할 수 있다.

책 목록 검색
  사용자는 홈 화면에서 책 목록을 확인할 수 있다.  
  각 책은 제목, 저자, 표지 이미지 등의 기본 정보와 함께 표시된다.  
  사용자는 검색창을 통해 원하는 책을 제목 또는 저자명으로 검색할 수 있다.  
  관심 있는 책은 즐겨찾기로 등록할 수 있으며, 이후 마이페이지나 즐겨찾기 목록에서 다시 확인할 수 있다.

구절 노트 작성 기능
  사용자는 특정 책을 선택한 뒤, 인상 깊거나 다른 사람과 이야기하고 싶은 짧은 구절을 등록할 수 있다.  
  구절 노트에는 책 제목, 저자, 페이지 또는 챕터 정보, 구절 내용, 사용자의 개인 주석이 포함된다.  
  저작권 문제를 고려하여 책 전체 내용이 아닌 짧은 구절만 등록할 수 있도록 입력 길이를 제한한다.  
  작성된 구절 노트는 공개 여부에 따라 다른 사용자에게 공유되거나 개인 기록으로 저장된다.

주석 교환 기능
  사용자는 다른 사용자가 공개한 구절 노트를 확인하고, 해당 구절에 대한 자신의 해석, 감상, 질문, 기타 등을 주석 형태로 남길 수 있다.  
  이를 통해 같은 구절에 대해 여러 사용자의 다양한 해석을 비교하고 독서 경험을 교환할 수 있다.

구절 탐색 기능
  사용자는 홈 화면에서 책 목록과 표지를 확인할 수 있다.  
  원하는 책을 선택하면 해당 책에 등록된 여러 구절 노트를 피드 형태로 둘러볼 수 있다.  
  사용자는 구절 노트 목록에서 관심 있는 구절을 선택하여 상세 내용을 확인할 수 있으며, 해당 구절에 자신의 감상이나 해석을 주석으로 남길 수 있다.

마이페이지 기능
  사용자는 자신이 작성한 구절 노트, 남긴 주석, 즐겨찾기한 책, 참여 중인 그룹 주석방을 한 곳에서 확인할 수 있다.

즐겨찾기 기능
  사용자는 마음에 드는 구절 노트나 다른 사용자의 주석을 즐겨찾기에 추가할 수 있다.  
  즐겨찾기한 구절과 주석은 마이페이지에서 다시 확인할 수 있으며, 사용자는 이를 통해 인상 깊었던 문장과 해석을 따로 모아볼 수 있다.

### 선택 기능

스포일러 표시 기능
사용자는 구절이나 주석에 스포일러가 포함되어 있는 경우 스포일러 여부를 표시할 수 있다.

그룹 주석방 기능
사용자는 특정 책을 중심으로 그룹 주석방을 만들고, 참여자들과 구절 및 주석을 공유할 수 있다.

1:1 대화 기능
사용자는 특정 사용자의 주석에 관심이 있을 경우 대화를 요청하고, 수락된 사용자와 1:1로 메시지를 주고받을 수 있다.

감정 태그 기능
사용자는 구절 노트에 감정이나 주제 태그를 추가하여 구절을 분류할 수 있다.

북마크 기능
사용자는 마음에 드는 구절 노트나 주석을 저장할 수 있다.

검색 기능
사용자는 책 제목, 저자, 키워드, 태그를 기준으로 구절 노트를 검색할 수 있다.

스포일러 표시 기능
사용자는 구절이나 주석에 스포일러가 포함된 경우 이를 표시할 수 있다.
