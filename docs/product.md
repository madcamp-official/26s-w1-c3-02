# Product Overview

## 프로젝트

**주석노트** (가제) — 책의 특정 구절에 주석·질문·토론을 남기고 공유하는 웹 서비스

카이스트 madCamp 공통과제 I (웹 기반 프로젝트, 2인 1팀) 결과물. 기획부터 배포까지 완료된 웹 서비스와 관련 문서 일체를 만드는 것이 목표.

## 목적

- 혼자 읽고 끝나던 독서 경험을, 책의 특정 구절에 주석·질문·토론을 남기며 생각을 기록하고 나눌 수 있는 경험으로 확장한다.
- 저작권 문제를 피하면서도 "책 속 특정 위치"에 메모를 고정할 수 있도록, 사용자가 직접 입력한 페이지·구절을 기준으로 주석을 관리한다 (책 본문 자체는 제공하지 않음).
- 공개/비공개 설정을 통해 개인 독서 노트와 공유형 독서 토론을 하나의 서비스에서 모두 지원한다.
- 주석을 남기는 사용자와 특정 구절의 해설·해석을 찾아보는 사용자를 연결하여, 한 권의 책을 매개로 한 집단 지성 독서를 지원한다.

## 핵심 기능

- **책 선정:** 홈 화면에서 주석을 달 책을 선택하거나 새로 등록 (제목·저자 등 기본 정보 입력)
- **주석 카드 작성:** 선택한 책에 대해 **질문 / 토론 / 감상 / 일반**(기본값) 유형의 카드를 생성. 저작권 보호를 위해 책 본문 대신 사용자가 직접 입력한 페이지 번호·인용 구절(길이 제한)로 카드를 연결
- **공개범위 설정:** 카드별로 `공개(public) / 친구공개(friends) / 그룹(group) / 비공개(private)` 4단계 지정 — 친구공개는 작성자의 친구에게만, 그룹은 해당 그룹 멤버에게만 노출
- **카드 열람·관리:** 책 단위로 주석 카드를 모아 보고, 유형별로 확인·수정·삭제
- **주석 검색:** 책의 페이지 번호 또는 구절/본문 키워드로 공개 주석 카드를 검색
- **친구 추가:** 닉네임으로 사용자를 검색해 친구 요청(`PENDING`) → 수락(`ACCEPTED`) 흐름으로 친구 관계 형성
- **그룹 주석방:** 친구 여부와 무관하게 멤버를 초대해 책 하나를 중심으로 주석방 생성 → 각자 구절 카드 업로드 → 서로 주석·댓글을 달며 토론
- **좋아요 · 즐겨찾기:** 주석 카드/댓글에 좋아요, 책/주석 카드는 즐겨찾기로 개인 보관

### 필수 기능 (기능 명세서)

1. 회원 관리 — 회원가입 및 로그인을 통한 개인 계정 사용
2. 책 목록 검색 — 제목/저자로 책 검색, 즐겨찾기 등록
3. 주석 카드 작성 — 책 제목·저자·페이지 정보와 인용 구절·주석 내용을 담아 주석 카드를 작성 (길이 제한으로 저작권 보호)
4. 댓글 — 다른 사용자가 공개한 주석 카드에 댓글(원글→댓글 2단 구조, 대댓글 없음)을 남김
5. 주석 탐색 — 책별 주석 카드 피드를 둘러보고 상세를 확인
6. 마이페이지 — 본인이 작성한 주석 카드, 즐겨찾기한 책, 참여 중인 그룹 주석방 확인
7. 친구 추가 — 닉네임 검색으로 친구 요청/수락, 친구와 그룹 주석방 생성·초대

### 선택 기능

- **즐겨찾기** — 마음에 드는 주석 카드를 즐겨찾기에 추가, 마이페이지에서 재확인
- **스포일러 표시** — 주석 카드 작성 시 스포일러 여부 선택, 스포일러 카드는 기본적으로 내용 블러 처리 후 클릭 시 노출
- **그룹 주석방** — 특정 책을 중심으로 그룹을 만들고 참여자들과 주석 카드 공유
- **좋아요** — 다른 사용자의 주석 카드/댓글에 공감 표시, 좋아요 수는 `likes` 테이블 집계로 노출

## 예상 사용자

- 읽은 책의 인상 깊은 구절과 생각을 구조적으로 기록하고 싶은 개인 독자
- 같은 책을 읽으며 질문과 해석을 나누고 싶은 독서 모임·스터디 참여자
- 특정 구절에 대한 토론을 남기고 공유하고 싶은 학생·연구자
- 이해가 안 되는 부분의 공개 주석을 검색해 도움을 얻으려는 독자 (주석 소비자)
